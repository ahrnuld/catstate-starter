# Virtual Cat
## Java example of the State pattern.

This is a small JavaFX application that demonstrates the state pattern. Your assignment is to implement the various state classes to make the virtual cat come alive.

You will need 3 classes:
* The sleeping cat
* The hungry cat
* The happy cat

Animations are already provided. Just check out the ExampleState class and implement your own solution.

Don't forget to modify the cat class to give it a starting state.

Good luck!
